# Personal Portfolio

My personal portfolio and hub for open source projects, built with React, TypeScript, and Tailwind CSS.

**Visit the live site:** [https://bitsarebits.github.io](https://bitsarebits.github.io)

---

## Tech Stack

- **Framework:** React 18+ (with Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React / Inline SVG
- **Deployment:** GitHub Pages (via GitHub Actions)
